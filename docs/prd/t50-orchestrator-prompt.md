# PRD — Ticket #50: Orchestrator prompt in each swimlane's settings

## Problem
Ticket #47 (branch `t47-auto-run-should`, not on main yet) adds an orchestrator agent: one extra tab per multi-ticket Auto Run, titled `AUTORUN-ORCHESTRATOR-<LANE>`, that watches the run's tickets, reports status and closes finished tabs. Its prompt is fully generated by `orchestratorPrompt(lane, launches, context)` in `src/shared/projectTypes.ts`. The user has no way to steer it per lane (e.g. "poll every 2 min", "flag PRs with failing checks", "don't close tabs in this lane").

This ticket adds an "Orchestrator prompt" field to each lane's settings (cog modal). Its text is appended to that lane's generated orchestrator prompt, the same way `agentPrompt` steers the per-ticket agents.

## Acceptance criteria
- [ ] Each lane's cog modal has an "Orchestrator prompt" textarea, below Output target, with helper text: "Extra instructions for the Auto Run orchestrator (runs when 2+ tickets auto-run)"
- [ ] The value saves on change and survives an app restart

- [ ] An empty or whitespace-only orchestrator prompt leaves the generated orchestrator prompt byte-for-byte unchanged
- [ ] The orchestrator prompt is never added to the per-ticket agent prompts (`ticketAgentPrompt` output unchanged)
- [ ] The unassigned lane gets the field too (it has a cog and can Auto Run)

## Decisions (defaults, no blockers)
- D1. Depends on #47. Build after #47 merges, on top of its `orchestratorPrompt`. If #47 is not merged when this starts, ship R1-R3 (field + storage + UI) and leave R4 for the #47 branch to pick up; the field is harmless with no consumer
- D2. Append, not replace. The generated prompt holds the safety rules (read-only DB, how to close tabs, done criteria). User text goes in a `Lane instructions` section after them, with one line: "Follow these unless they conflict with the rules above"
- D3. Plain text only. No orchestrator markdown file path (unlike `agentFilePath`). Add one later if someone asks
- D4. Field `orchestratorPrompt?: string` on `SwimLane`, column `orchestrator_prompt TEXT NOT NULL DEFAULT ''`. Optional so older lanes load as empty
- D5. Which lane's text is used: the lane whose Auto Run button started the run. Full auto handoffs to later lanes don't swap in the later lane's orchestrator prompt (#47 runs one orchestrator per Auto Run)
- D6. "Send a prompt to the Orchestrator Agent" = this text is part of its launch prompt. No live messaging into a running orchestrator tab
